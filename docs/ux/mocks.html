Fediverse actions: UX mocks

Every flow of the proposed design, drawn as the real page at phone width in a plain frame. The page is a web page using the browser's own elements and system colours, styled by style.css only (see components.md). There is no theme toggle: light and dark follow the device. Screens are titled by what the person is doing, not by a product name. The label above a frame says where the page runs: Safari, or the Home Screen app. Screen IDs (A1, B3…) match docs/ux/review.md.

H · Edge cases

I · Added to the Home Screen

Goal: open the tool like an app, with no browser bar. iOS keeps a Home Screen web app’s storage separate from Safari’s, so sign-ins are not shared. A link opened from the Shortcut loads in Safari, not in the Home Screen app. The design has to work well in both. The Web Share Target API isn’t available on iOS, so the Shortcut stays for sharing.
