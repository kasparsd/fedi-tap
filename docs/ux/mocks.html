Fediverse actions: UX mocks

Every flow of the proposed design on iPhone. The interface is neutral: system font, system colours, no logo, no decoration, no theme toggle. Dark mode follows the device automatically (prefers-color-scheme). Screens are titled by what the person is doing, not by a product name. Screens marked Home Screen app run standalone; Safari screens show the browser bar. Screen IDs (A1, B3…) match docs/ux/review.md.

H · Edge cases

I · Added to the Home Screen

Goal: open the tool like an app, with no browser bar. iOS keeps a Home Screen web app’s storage separate from Safari’s, so sign-ins are not shared. A link opened from the Shortcut loads in Safari, not in the Home Screen app. The design has to work well in both. The Web Share Target API isn’t available on iOS, so the Shortcut stays for sharing.
